How a prompt gets processed in ArenaURP

From the moment you type a prompt to the artifacts it leaves behind. The whole thing hangs on one branch point: is this leaf/dev-only work (fast-path) or does it touch networked/core code (the gauntlet)? Hooks classify on the way in; subagents do the noisy work; the mattpocock flow governs anything coupled.

The one rule of thumb: the habit-check hook and the delegation skill both push you to answer "does this touch SyncVar/RPC/[Server]/the hit-exchange web?" first. If no → fast-path (try + verify). If yes → the full /grill-with-docs → /to-spec → /to-tickets → /implement → /code-review gauntlet, and every networked change earns a PlayMode test.
