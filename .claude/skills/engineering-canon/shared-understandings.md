- 2026-07-19 · Constantine/Parnas — cross-component gameplay coupling follows the LAYERED MODEL (ADR 0005): a fan-out context earns a pooled `ExecuteEvents` message only at ALL FOUR clauses — ≥2 unrelated responders, same-GameObject, same-peer, synchronously served (the one-clause form was calibrated on N=1 and greenlights peer-disjoint promotions that break silently, e.g. `PawnManager.OnPawnKilled` → the client ragdoll); cross-peer fan-out rides `SyncVar.OnChange` (ADR 0004); off-hierarchy fan-out stays a C# event or a `MatchMediator` wire; a single-receiver operation is a direct call into a public operation API. - 2026-07-19 · Parnas/Dijkstra — a component named `<X>Controller` OWNS STATE and exposes an API to modify it; controllers are the state-owning half of the messaging/dispatch pattern (messages fan out; controllers hold state and expose the operations handlers call).
